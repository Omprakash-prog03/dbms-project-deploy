ACID Transaction Atomicity & Concurrency Test

Demonstrates that multi-statement transactions execute with absolute atomicity: either all changes commit, or ROLLBACK restores the database with zero side effects.

Protocol Executed on Database:

  1. START TRANSACTION; opens a private transaction context.
  2. First student insert succeeds into the transaction log buffer.
  3. Second student insert deliberately violates the UNIQUE(roll_no) constraint.
  4. Database engine raises an integrity constraint violation exception.
  5. Application exception handler immediately issues ROLLBACK;.
  6. Final student count is verified against the initial count: Delta is guaranteed 0.
