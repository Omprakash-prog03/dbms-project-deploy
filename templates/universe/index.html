What this module is

A real relational schema

Fourteen tables in third normal form, nineteen foreign keys, seven reporting views. The same DDL ships as MySQL 8 in db/universe_schema.sql and is translated for the embedded engine by a tested dialect layer, so both engines get the same model.

Canon where it exists, NULL where it does not

First appearances, directors and creators are the published ones. Where a credit is genuinely not established the cell is blank, and the data dictionary counts how many cells that is, instead of inventing a name.

Demonstrable SQL

{% if current_user.role == 'admin' %}The SQL gallery{% else %}The SQL gallery{% endif %} runs fifteen documented queries over this data — joins, aggregates, HAVING, nested queries and subqueries — and shows the rows they return.

Verified, not asserted

Every row was validated before insertion and re-read afterwards. The validation report, the insertion log and the live foreign-key check are all on the {% if current_user.role == 'admin' %}verification page{% else %}verification page{% endif %}.
