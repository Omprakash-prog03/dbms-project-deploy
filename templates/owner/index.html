How it works

Nothing to configure.

  1. You are the owner. The first administrator account, or the one named in OWNER_USERNAME.
  2. Other admins need a code. Their password alone is not enough — you issue a six-digit code here, valid once for {{ code_minutes }} minutes.
  3. One tap signs them out. A lockdown ends every other administrator session at once; only yours continues.
  4. Codes are hashed. Only you ever see the plaintext code, once.
